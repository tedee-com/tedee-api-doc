Switch mode
---------------------------------------

This enum describes possible switch operating modes

+--------+------------+---------------------------------------------------------------+
| Number | Name       | Description                                                   |
+========+============+===============================================================+
| 1      | Gate       | switch opens a gate or door when the open action is triggered |
+--------+------------+---------------------------------------------------------------+
| 2      | DryContact | switch works as a dry contact and can be paired with a lock   |
+--------+------------+---------------------------------------------------------------+
