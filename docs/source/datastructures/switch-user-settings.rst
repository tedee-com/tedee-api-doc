Switch user settings
--------------------

+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| Name                            | Type                       | Description                                                                                                                               |
+=================================+============================+===========================================================================================================================================+
| autoUnlockBleSignalStrength     | number                     | minimum BLE signal strength required by auto unlock: 0 = close, 1 = medium, 2 = far, null = check disabled; in update -1 clears the value |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockCancelOtherAutoUnlock | boolean                    | is auto unlock canceling by other auto unlock enabled                                                                                     |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockCheckDeviceMovements  | boolean                    | is checking device movements in auto unlock enabled                                                                                       |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockCheckWiFi             | boolean                    | is WiFi checking in auto unlock enabled                                                                                                   |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockConfirmEnabled        | boolean                    | is confirm to auto unlock enabled                                                                                                         |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockEnabled               | boolean                    | is auto unlock enabled                                                                                                                    |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockRangeIn               | number                     | value of the in zone                                                                                                                      |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockRangeOut              | number                     | value of the out zone                                                                                                                     |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| autoUnlockTimeout               | number                     | value of auto unlock timeout                                                                                                              |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| favorite                        | boolean                    | is device added to favorites                                                                                                              |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| location                        | :doc:`Location <location>` | geographic location used by auto unlock; in update an empty object clears the value                                                       |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| notifications                   | object                     | notification settings of the current user for this switch                                                                                 |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
| wiFiName                        | string                     | WiFi name for checking in auto unlock; in update an empty string clears the value                                                         |
+---------------------------------+----------------------------+-------------------------------------------------------------------------------------------------------------------------------------------+
